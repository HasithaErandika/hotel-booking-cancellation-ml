## How to add a new decision

Append a new row with the next number. Keep the "Evidence" column concrete
(a computed number, a specific check, a citation), "it seemed reasonable" is not
evidence. If a later decision reverses an earlier one, don't delete the old row;
add a new row referencing the old decision number and explaining what changed and
why.
